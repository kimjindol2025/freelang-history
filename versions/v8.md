## 3. 어떤 언어인가

- README(원문):

> # FreeLang v8 ML
> AI/ML 특화 언어 — tensor 1급 시민, 자동미분 내장
> - **tensor가 기본 타입** — int/float처럼 언어 수준에서 지원
> - **shape 타입 시스템** — 컴파일 타임 shape 오류 검출
> - **autodiff 내장** — 외부 라이브러리 없이 역전파

  (tensor=숫자를 여러 차원으로 묶은 표, autodiff=자동 미분, 역전파=신경망 학습 계산 방법)
- 문법 모양: **중괄호형**, `let`, `fn … -> 타입`, 행렬곱 연산자 `@`.
- 예제 파일 이름: `hello`, `tensor`, `autograd`, `nn`, `attention`, `transformer`, `gpt_tokenize`, `classifier` 등.

실제 예제 (`examples/hello.fl8` 일부, 원문):

```
print("=== FreeLang v8 ML ===")
let x = 10
let y = 3.14
print("x + y =", x + y)

let w = randn(3, 4)
print("w shape:", shape(w))

let a = [[1.0, 2.0], [3.0, 4.0]]
let b = [[5.0, 6.0], [7.0, 8.0]]
let c = a @ b
print(c)
```

## 4. 상태 (이번 조사에서 직접 실행 — 본 저장소판)

- `npx ts-node --transpile-only src/fl8.ts examples/hello.fl8` → "x + y = 13.14", "w shape: [3, 4]", 행렬곱 결과 `[19, 22] / [43, 50]` **정상 출력**.
- `npm test`(`ts-node tests/run.ts`) → 실행 파일을 찾지 못해 실패.
