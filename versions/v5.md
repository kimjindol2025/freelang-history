## 3. 어떤 언어인가

- README의 목표(원문):

> FreeLang v5는 **AI가 주도적으로 코드를 생성하고 최적화**하는 차세대 프로그래밍 언어입니다.
> **The Next Generation of Programming: Human 10% + AI 90%**

- README가 그린 흐름: "사용자 의도 (자연어) → Intent Parser (AI 처리) → v4 형식 (메타 명세) → 다국어 자동 생성 (TypeScript/C/Python/Go/Rust) → 자동 최적화 + 보안 검증".
- 즉 **사람이 쓴 의도를 여러 언어 코드로 바꿔 주는 코드 생성기** 성격이 강합니다.
- `.v5` 예제의 문법 모양: 중괄호형, 타입을 `-> number`처럼 적음.

실제 예제 (`fibonacci.v5` 일부, 원문):

```
fn fib(n: number) -> number {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}

fn main() -> void {
  var f10 = fib(10);
  print("fib(10) =", f10);
}
```

## 4. 상태 (이번 조사에서 직접 실행)
