## 3. 어떤 언어인가

- 문법 모양: **중괄호형·자바스크립트 비슷한 형태**. `let`, `fn`, 클로저, `import "math" as M`, `import { mul } from "math"`, `enum`.
- 커밋 기록에 나오는 작업: 제네릭 타입, enum(태그된 유니온), 패턴 매칭의 C 코드 생성(`--emit-c`), clang으로 실행 파일 만들기(`--build`).
- README는 짧고, 목적 대신 보관 상태만 적혀 있습니다(원문):

> **Status**: 🔴 Archived | **Type**: Legacy | **Language**: Rust/FreeLang
> **Archive Date**: 2026-03-15

실제 예제 (`examples/app.fl`, 원문):

```
// FreeLang v6: Module import demo
import "math" as M

println("PI = " + M.PI)
println("3 + 4 = " + M.add(3, 4))

import { mul } from "math"
println("6 * 7 = " + mul(6, 7))
```

(`examples/hello.fl`에는 `fn counter() { let c = 0  return fn() { c = c + 1  return c } }` 같은 클로저 예제가 있습니다.)
