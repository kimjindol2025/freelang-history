## 3. 어떤 언어인가

- 문법 모양: **괄호 목록형(리스프 계열)**. `(define ...)`, `(let [[$x 1]] ...)`, 변수 앞에 `$`, 대괄호 블록 `[FUNC ...]`, `[ROUTE ...]`도 씀.
- README(2026-04-18 커밋에서 삭제되기 직전 판) 첫머리(원문):

> # FreeLang v9 & v10
> **AI를 위한, AI에 의한, AI가 쓰고 싶은 언어.**

- `STATE_OF_V9.md`("공식 현황 선언 (2026-04-18)")는 스스로를 이렇게 평가합니다(원문):

> **코어 인터프리터** ✅ 완성 | TypeScript/Node.js | **외부 언어 의존**
> **v9로 작성된 부분** ~30% | 평가기 일부만
> 현재 v9: ❌ 이 조건을 만족하지 않음 (진정한 Self-Hosting)

실제 예제 (`examples/hello.fl` 일부, 원문):

```lisp
; FreeLang v9 — 기본 예제
(println "Hello, FreeLang v9!")

(let [[$name "Claude"]
      [$ver 9]]
  (println "나는 {$name}이고, 이건 FreeLang v{$ver}다."))
```

대괄호 블록 형태 (`examples/api-server.fl` 일부, 원문):

```
[FUNC greet
  :params [$name]
  :body (concat "Hello, " $name "!")
]
```

AI 호출을 언어 기본 기능으로 넣은 예 (`examples/ai-agent.fl` 일부): `(define analysis (ai-call "claude-3" code-review-prompt))` — 주석에 "모든 함수는 mock(흉내)으로 동작"이라고 적혀 있음.

## 5. 다른 FreeLang 이름 언어와 구별되는 점

- **괄호 목록형 문법 + `[FUNC]`·`[ROUTE]` 같은 대괄호 선언 블록**을 함께 쓰는 점, 그리고 `ai-call`, `prompt-template`, `rag-search` 같은 AI 기능을 언어 기본 함수로 둔 점.
- 사실 관찰(공유 기록): kim27의 `platform/freelang-afj` 저장소는 **첫 커밋이 `freelang-v9`와 같습니다**(커밋 f2ece2176a, 2026-04-03 20:08). 즉 두 저장소의 Git 기록 앞부분이 같습니다. 또 AFJ 문서가 "v10 [FUNC] 문법"이라고 부르는 대괄호 형태가 이 저장소 예제 61개 파일에 나옵니다.
- 표어가 AFJ Language의 표어("AI를 위한, AI에 의한, AI가 원한 언어.")와 거의 같습니다.
