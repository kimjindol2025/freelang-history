## 3. 어떤 언어인가

- 문법 모양: **중괄호 `{ }`와 `fn`을 쓰는 C·자바스크립트 비슷한 형태**. 확장자 `.fl`, `.free`.
- README가 밝힌 목적(원문):

> FreeLang은 **자기 자신의 소스를 컴파일 및 린트할 수 있는** 제로 외부 의존성 AI 기반 프로그래밍 언어입니다.

- "핵심 원칙": Zero-Dependency, Self-Hosting(`compiler.free`가 컴파일러 자신을 컴파일), Self-Linting, "Replace Everything"(ESLint / Apollo / PM2 / Swagger / nodemailer 대체).
- `freelang-v2-language-spec` README: "**순수 구현, 기록 기반, 안전/유연성 보장, 모듈화, 데이터 중심, 확장 가능**을 핵심 원칙으로 하는 시스템 프로그래밍 언어".
- 이름과 README 제목이 다른 경우: `v2-freelang-ai` 백업 README 제목 "FreeLang v4.0 — Phase 4B Complete", `freelang` README "FreeLang v2.2.0", `freelang-v2` README "FreeLang v2.8.0". 본 저장소 `v2-freelang-ai`의 마지막 커밋은 "docs: v1.0.2 release preparation".

실제 예제 (`examples/ackermann.fl`, 원문):

```
fn ackermann(m, n) {
  if (m == 0) {
    return n + 1;
  }
  if (n == 0) {
    return ackermann(m - 1, 1);
  }
  return ackermann(m - 1, ackermann(m, n - 1));
}

let result = ackermann(3, 3);
println(result);  // Expected: 61
```
