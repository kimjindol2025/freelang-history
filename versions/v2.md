## 3. 어떤 언어인가

- 문법 모양: **중괄호 `{ }`와 `fn`을 쓰는 C·자바스크립트 비슷한 형태**. 확장자 `.fl`과 `.free`.
- README가 밝힌 목적(원문):

> FreeLang은 **자기 자신의 소스를 컴파일 및 린트할 수 있는** 제로 외부 의존성 AI 기반 프로그래밍 언어입니다.

- README의 "핵심 원칙" 표: Zero-Dependency(외부 npm 패키지 없음), Self-Hosting(`compiler.free`가 컴파일러 자신을 컴파일), Self-Linting(`@lint` 표시로 검사), "Replace Everything"(ESLint / Apollo / PM2 / Swagger / nodemailer 대체).
- `freelang-v2-language-spec` README의 소개: "**순수 구현, 기록 기반, 안전/유연성 보장, 모듈화, 데이터 중심, 확장 가능**을 핵심 원칙으로 하는 시스템 프로그래밍 언어".
- 저장소 이름과 README 제목이 서로 다른 경우가 있습니다: `v2-freelang-ai` README 제목은 "FreeLang v4.0 — Phase 4B Complete", `freelang` README는 "FreeLang v2.2.0", `freelang-v2` README는 "FreeLang v2.8.0".

실제 예제 (`freelang-v2/examples/ackermann.fl`, 원문 그대로):

```
fn ackermann(m, n) {
  if (m == 0) {
    return n + 1;
  }
  if (n == 0) {
    return ackermann(m - 1, 1);
  }
  return ackermann(m - 1, ackermann(m, n - 1));
}

let result = ackermann(3, 3);
println(result);  // Expected: 61
```

## 4. 상태 (이번 조사에서 직접 실행)

- 이 컴퓨터(조사용 상자)에 `freelang-v2`를 복제해 `npm install` → `tsc`(TypeScript 변환)를 돌렸더니 **타입 오류 300건**이 나왔지만 결과 파일은 만들어졌습니다(`build` 스크립트도 `tsc || true`로 오류를 무시하게 되어 있음).
- `node dist/cli/index.js examples/ackermann.fl` → **61 출력(정상)**. 직접 쓴 `fn add(a, b) { return a + b; } println(add(2, 3));` → **5 출력**. 실행할 때마다 "Native function already registered" 같은 안내 문구가 여러 줄 함께 나옵니다.
- 테스트 묶음 전체(jest)는 돌리지 않았습니다(**확인 안 됨**). `COMPLETION-PLAN-v3.0.0.md`에는 "99.89% 통과 (2,701/2,701 tests)"라는 문구가 있고, `freelang-v4`의 문서는 v2 테스트가 "OOM Killed"(메모리 부족으로 중단)라고 적었습니다. 서로 다른 주장입니다.
- 마지막 활동: 2026-03-13(`freelang-v2` 커밋), GitHub 푸시는 2026-03-30.

## 5. 다른 FreeLang 이름 언어와 구별되는 점

- 규모가 가장 큽니다(TypeScript 40만 줄대). 언어 안에 Git 훅·린트·웹서버·ORM 등 **개발 도구를 통째로 넣겠다는 목표**("Replace Everything")가 두드러집니다.
- 코드 공유 관찰: `freelang-v4-runtime` 저장소의 `src` 파일 중 **379개가 `freelang` 저장소의 같은 경로 파일과 글자 하나까지 같습니다**(410개 공통 경로 중). 두 이름이 코드 일부를 함께 쓴 사실만 적어 둡니다.
