## 3. 어떤 언어인가

- 목적: 한 언어로 **백엔드 + 프론트엔드 + 운영**까지 만드는 풀스택 플랫폼. 본 저장소 구조가 `app/`(화면 페이지 `.fl`), `backend/`(인증·DB·GraphQL·OAuth·웹소켓 `.fl`), `components/ui/`(버튼·카드·표), `services/`(게이트웨이·Kafka·Redis 등)로 되어 있습니다. 데이터는 직원·고객·운행(trips)·정산 같은 업무 앱 모양입니다.
- `freelang-v9` 저장소 README(삭제 직전 판, 원문): "**v10.0.0** (2026-04-16) 은 **백엔드 + 프론트엔드 + 인프라**를 한 언어로 통합하는 진정한 풀스택 플랫폼입니다."
- 문법 모양: **괄호 목록형(스킴 계열)**. 본 저장소 백엔드는 `(define (함수 인자) …)` 모양을 씁니다.

실제 예제 (본 저장소 `backend/main.fl` 일부, 원문):

```lisp
;;; FreeLang v10 - Training System Integration
(include "training.fl")

(define DB_PATH "./data/bigwash.db")

(define (get-employees)
  (db_query DB_PATH "SELECT * FROM employees" (list)))

(define (get-employee id)
  (let ((result (db_query DB_PATH "SELECT * FROM employees WHERE id = ?" (list id))))
    (if (and result (> (length result) 0))
      (car result)
      null)))
```

- `freelang-afj` 문서가 "v10 문법"이라며 드는 예: `[FUNC add :params [a b] :body (+ a b)]`, `(let [x 1 y 2] (+ x y))`.

## 4. 상태 (이번 조사에서 직접 실행)

- 본 저장소판을 가져와 FreeLang v9 해석기 위치를 지정하고 `node bootstrap.js run`으로 `(define (sq x) (* x x)) (println (sq 7))`을 실행 → **실패**: "v9 인터프리터 로드 실패 — Cannot find module '/home/kimjin/freelang-v9/node_modules/ws'". FreeLang v9 해석기에 원래 개발 컴퓨터 경로가 박혀 있어서, v9에 의존하는 v10도 다른 컴퓨터에서는 그대로 돌지 않습니다.
- 운영 흔적: 커밋 "feat: 포트 보호 정책 구현 - V10 서비스 보호(43000-43999)"(04-19), `package.json`의 PM2 명령(`v10-backend` 등). `freelang-afj/docs/CLAUDE.md`에도 "v10 보호 43000-49999"라는 포트 규칙이 있습니다. 지금도 돌아가는지는 **확인 안 됨**(PM2는 조회하지 않음).
