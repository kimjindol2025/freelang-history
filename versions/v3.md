## 3. 어떤 언어인가

- README 첫머리(원문):

> **Version**: 3.0.0 (Production Ready)
> **Status**: ✅ **OFFICIALLY RELEASED** - Complete Independent Language
> **Language**: V3 (Dynamic Typing, Python-style syntax)

- 문법 모양: **파이썬처럼 들여쓰기와 콜론(`:`)을 쓰고, 타입·명령어를 대문자로 쓰는 형태**(`INT`, `STR`, `IF … :`, `FUNC … -> INT:`, `CALL`). 동적 타입(실행할 때 타입이 정해짐).
- 두 가지 모드: "AI Intent 모드"(자연어 의도 → 중간 코드 생성·실행·패턴 저장)와 일반 프로그래밍 언어 모드(v3.1.0부터라고 README에 적힘).

README의 예제(원문 일부):

```
INT x = 10
ARR nums = [1, 2, 3, 4, 5]
ARR_SUM nums -> total
println(total)   # 15

IF x > 5:
  println("big")
ELSE:
  println("small")

FUNC add(a: INT, b: INT) -> INT:
  RETURN a + b

result = CALL add(3, 4)
```

## 4. 상태 (이번 조사에서 직접 실행)

- 본 저장소를 조사용 컴퓨터로 가져와 실행.
- 공식 실행 명령 `node bin/freelang run test1.v3`(`INT x=10, y=20, z=x+y, println(z)`) → 화면에 30이 나오지 않고 "✅ Result: undefined"만 출력.
- 저장소의 별도 시험 도구 `node test-v3-runner.js` → 예제 4개 중 **3개 통과**(30, 15, "big"), 1개 실패(기대값 5).
- 테스트 묶음(jest)은 이번에 결과를 얻지 못했습니다(**확인 안 됨**). `package.json` 설명은 "244/244 tests"라고 주장합니다.

## 5. 구별되는 점

- **대문자 명령어 + 파이썬식 들여쓰기**라는, 다른 FreeLang 이름 언어들에 없는 문법 모양.
- "AI 의도 → 중간 코드 → 실행 → 패턴 저장" 흐름을 언어 안에 넣은 점.
