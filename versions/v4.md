## 3. 어떤 언어인가

- 문법 모양: **중괄호형, 타입 표기(`i32` 등) 있는 정적 타입 스타일**. `var`, `let`, `fn`, `for x in ...`. 본 저장소 판에는 `;` 주석도 추가됨.
- 본 저장소 README(원문): "**프로젝트**: FreeLang v4 - AI-First Programming Language / **버전**: 4.3.0 / **테스트**: 251개 통과 / 263개 (95%)".
- 백업판 README(원문): "FreeLang v4는 **완전한 프로그래밍 언어**입니다. 형식 언어 스펙 (LANGUAGE_INDEPENDENT_SPEC.md), 완전한 구현체 (Lexer → Parser → TypeChecker → Compiler → VM)".
- `freelang-v4-runtime` README의 목표(원문): "모든 런타임 (TypeScript, Python, C, Go, Rust)에서 동일한 결과 생성".

실제 예제 (`examples/arrays.fl` 일부, 원문):

```
var numbers = [5, 2, 8, 1, 9, 3]
var sorted = sort(numbers)
for x in sorted {
  println(str(x))
}
```

## 5. 구별되는 점

- 정적 타입 + 바이트코드 가상머신(명령어를 차례로 실행하는 작은 가상 컴퓨터).
- "언어 독립 명세"를 목표로 적은 점(`freelang-v4-runtime`).
- 코드 공유 관찰: `freelang-v4-runtime`의 `src` 파일 379개가 번호 없는 `freelang` 저장소(FreeLang v2 기록) 파일과 똑같습니다. 또 본 저장소 `freelang-v8-ml` README는 "lexer/parser/ast/vm/ir"의 출처를 `freelang-v4`라고 적었습니다.
