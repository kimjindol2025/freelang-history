## 2. 무엇으로 만들었나 / 규모

- `freelang-v4`: **TypeScript** 37개 / 13,735줄(테스트 포함), 예제 `.fl` 21개 / 2,196줄. 소스가 `src/` 한 폴더에 모여 있음(`lexer`, `parser`, `checker`, `compiler`, `vm` 등).
- `freelang-langv4`: TypeScript 55개 / 18,597줄, `.fl` 167개 / 36,376줄.
- `freelang-v4-runtime`: TypeScript 413개 / 129,661줄. `freelang-v4-core`: FreeLang 코드(.fl) 34개 / 20,306줄.

## 3. 어떤 언어인가

- 문법 모양: **중괄호형, 타입 표기(`i32` 등) 있는 정적 타입 스타일**. `var`, `let`, `fn`, `for x in ...`.
- README 소개(원문):

> FreeLang v4는 **완전한 프로그래밍 언어**입니다.
> - 형식 언어 스펙 (LANGUAGE_INDEPENDENT_SPEC.md)
> - 완전한 구현체 (Lexer → Parser → TypeChecker → Compiler → VM)

- `package.json` 설명: "FreeLang v4 - AI-First Programming Language (334/334 tests passing)", 핵심어에 `static-typing`, `bytecode-vm`.
- `freelang-v4-runtime` README의 목표(원문): "모든 런타임 (TypeScript, Python, C, Go, Rust)에서 동일한 결과 생성". 부제 "KimNexus 공식 프로그래밍 언어 - Language-Independent 구현".
- `freelang-v4-core`의 `.fl` 파일은 `#` 주석과 `CALC_PLUS = "plus"` 같은 파이썬 비슷한 모양입니다(같은 v4 이름이라도 저장소마다 문법 모양이 다름).

실제 예제 (`freelang-v4/examples/arrays.fl` 일부, 원문):

```
var numbers = [5, 2, 8, 1, 9, 3]
var sorted = sort(numbers)
for x in sorted {
  println(str(x))
}
```

(`examples/factorial.fl`은 `fn factorial(n: i32): i32 { ... }` 모양인데, 아래처럼 지금 파서에서 오류가 납니다.)

## 4. 상태 (이번 조사에서 직접 실행)

- 조사용 상자에 `freelang-v4`를 복제해 설치·변환(`tsc`) → **오류 없이 성공**.
- 테스트(`jest`): **8개 묶음 모두 통과, 213개 테스트 통과 / 213개**. (README는 213/213, `package.json` 설명은 334/334라고 적혀 있어 숫자가 서로 다름.)
- 예제 실행: `hello.fl` → "Hello, FreeLang v4!", `fizzbuzz.fl`·`arrays.fl` 정상 출력. **`factorial.fl`은 실패** — "parse error: expected '->' for return type (got COLON)". 예제는 반환 타입을 `:`로 쓰는데 파서는 `->`를 기대합니다.
- `freelang-langv4` README 주장: "테스트: 251개 통과 / 263개 (95%)"(실행하지 않음, **확인 안 됨**).
- 마지막 활동: `freelang-langv4` 2026-04-05.

## 5. 다른 FreeLang 이름 언어와 구별되는 점

- 본체(`freelang-v4`)가 **작고 한 폴더에 모인 구조**(TypeScript 약 1만 4천 줄)에, 정적 타입과 바이트코드 가상머신(명령어를 차례로 실행하는 작은 가상 컴퓨터)을 둔 점.
- "언어 독립 명세"(어떤 구현 언어로 만들어도 같은 결과)를 목표로 적은 점(`freelang-v4-runtime`).
- 코드 공유 관찰: `freelang-v4-runtime`의 `src` 파일 379개가 번호 없는 `freelang` 저장소(FreeLang v2 코드 기록) 파일과 똑같습니다.
