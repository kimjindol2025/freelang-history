## 2. 무엇으로 만들었나 / 규모

- `freelang-v12`: **FreeLang 코드(.fl) 34개 / 3,333줄** + 한 파일로 묶인 자바스크립트 실행기 `bootstrap.js`(36,420줄). 패키지 폴더(`.packages/`, `lib/`)에 auth-common, crypto-common, db-common, http-common, dclub-auth 등.
- `v12-alpha`: TypeScript 5개, `.fl` 6개, `bootstrap.js`, 문서(`v12-DESIGN.md`, `MISTAKES-100.md`).

## 3. 어떤 언어인가

- `freelang-v12/ARCHITECTURE.md`(원문): "FreeLang v12는 **모듈화 기반의 AI 에이전트 실행 엔진**입니다." 계층: 커뮤니티 에이전트 → 마켓플레이스(에이전트 등록소·패키지 관리자·플러그인) → 표준 라이브러리 모듈.
- `v12-alpha/README.md`: 환경변수 `FL_V12=1`을 켜면 바뀌는 규칙들(예: 같은 이름 재정의를 오류로, 바뀌는 값은 `atom`으로).
- 문법 모양: **괄호 목록형 + `[FUNC …]` 대괄호 블록**.

실제 예제 (`freelang-v12/lib/audit-common/logger.fl` 일부, 원문):

```
(define LOG-LEVELS {
  :debug 0
  :info  1
  :warn  2
  :error 3
  :fatal 4
})

[FUNC log-level-num :params [$level]
  :body (get LOG-LEVELS $level)]
```

`v12-alpha` README 예제(원문):

```lisp
(define x (atom 1))
(swap! x + 1)   ;; @x → 2
```

## 4. 상태 (이번 조사에서 직접 실행)

- `freelang-v12`: `node bootstrap.js run`으로 `(define sq (fn [x] (* x x)))`와 `[FUNC add :params [$a $b] :body (+ $a $b)]` 실행 → **49, 5 정상 출력**(추가 설치 없음).
- `v12-alpha`: `npm install` 후에도 `bootstrap.js`가 "Cannot find module 'better-sqlite3'"로 **실패**(`package.json`에 그 부품이 적혀 있지 않음).
- 마지막 활동: 2026-05-17(`v12-alpha`).

## 5. 구별되는 점

- **패키지·플러그인·에이전트 마켓플레이스**를 중심에 둔 점(`freelang-v12`).
- 같은 이름 아래 성격이 다른 두 저장소가 있습니다: 패키지 중심의 `freelang-v12`, 규칙 변경 실험인 `v12-alpha`.
